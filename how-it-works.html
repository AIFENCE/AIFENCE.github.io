How it works / one governed transaction

Intent becomes
an explicit outcome.

The composed fence takes one authenticated request through artifact admission, mandatory authorization, durable delivery, and completion evidence.

Run the interactive simulation
01 · Authenticate

Resolve the caller into the same Guard-backed identity model used by the fence and governed endpoints.

02 · Admit

Quality emits explicit mode/profile metadata and stable finding IDs.

03 · Enforce

Guard compiles policy into an enforcement decision and exact-action capability. Errors fail closed.

04 · Persist

Bus creates a tenant-scoped handoff before broker fan-out or delivery claims.

05 · Evidence

The completion event appends stage truth, request identity, hashes, and signing identity into the audit path.

Failure semantics

A failure is part of the contract.

blocked_by_quality

Artifact admission failed; Guard and Bus are not falsely represented as completed.

blocked_by_guard

Policy denied or held the action. Bus does not create a governed handoff.

unavailable

Required persistence/evidence failed. Authorization never turns into a false delivery receipt.

SDKs

Python, TypeScript and Go clients, plus agent-framework enforcement hooks.

Official SDKs are versioned on the 1.0.0rc5 compatibility line and live under sdks/.

LanguagePathPackage / module
Pythonsdks/pythonaifence-client / aifence_client
TypeScriptsdks/typescript@aifence/client
Gosdks/gogithub.com/aifence/aifence-go

#Guard client

Point the client at the Guard mount for direct decision, capability, approval, policy, execution and audit operations.

python
from aifence_client import AifenceClient

client = AifenceClient(
    "https://aifence.example.com/guard",
    api_key="replace-with-secret-manager-value",
)
decision = client.decide({...})

#Full composed fence

The same clients expose the root composed transaction and correctly resolve it outside the /guard mount.

python
receipt = client.submit_fence({
    "artifact": "# Deployment note\n\nValidated for controlled handoff.",
    "receiver": "release-agent",
    "action": {"operation": "read"},
    "risk_score": 10,
})
print(receipt["final_outcome"])

TypeScript uses submitFence(...); Go uses SubmitFence(...). All target POST /v1/fence/submit.

#Client behavior

Clients require HTTPS, use bounded timeouts/retries, do not follow redirects, cap response sizes, and expose AIFENCE structured errors. Python additionally supports mTLS.

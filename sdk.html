SDKs

Python, TypeScript and Go clients, plus agent-framework enforcement hooks.

Maintained clients live under sdks/.

| Language | Path | Package identifier | | --- | --- | --- | | Python | sdks/python | agentdance_client | | TypeScript | sdks/typescript | @agentdance/client | | Go | sdks/go | agentdance |

Package identifiers are held stable so existing integrations keep compiling.

#Base URL: point at the Guard mount

Guard is mounted at /guard and clients append /v1/... to the base URL:

text
https://aifence.example.com/guard  →  https://…/guard/v1/decisions

HTTPS is required by every client.

python
from agentdance_client import AgentDanceClient
client = AgentDanceClient("https://aifence.example.com/guard", api_key)

#Framework integrations

The Python SDK includes framework-neutral hooks for OpenAI Agents, LangGraph, CrewAI, AutoGen and Semantic Kernel. Each wrapper submits a tool call for a decision before it executes; a denied decision raises rather than returning control to the tool.

#Two entry points

| Endpoint | Use when | | --- | --- | | POST /guard/v1/decisions | Enforcement decision only. | | POST /v1/fence/submit | Full Quality → Guard → Bus pipeline. |

#Client behavior

All clients use explicit timeouts, capped retries with Retry-After awareness, no redirect following, maximum response size and AIFENCE's structured error envelope (code, message, details, request_id).

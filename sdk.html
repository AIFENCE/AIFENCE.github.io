Developer tools

SDKs

Integrate the fence from Python, TypeScript, or Go clients and framework hooks.

Client strategy

SDKs wrap the same HTTP contract exposed by the composed service. Keep policy and authority server-side; clients should submit intent and consume receipts rather than reimplementing enforcement locally.

Core workflow

  1. Create a client with a guard-issued API key.
  2. Submit an artifact and action to the fence flow.
  3. Inspect the stage receipt and final outcome.
  4. Claim the durable handoff when the flow reports delivery.

Contract-first integrations

Use the API reference and generated OpenAPI contract when building custom clients.

Core concepts

Architecture

A single application factory composes Quality, Guard, and Bus over one shared foundation.

Composed control plane

aifence.app.create_app() owns the shared foundation—configuration, database, errors, middleware, metrics, and telemetry—then mounts installed subsystems through a registration seam.

Design constraints

  • No import-time database work and no module-level application singleton.
  • Each subsystem registers itself into a shared application context.
  • Failures report the actual terminal outcome rather than claiming success.
  • The enforcement tier remains fail-closed by design.

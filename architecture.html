Architecture / one composed control plane

Shared foundation.
Independent contracts.

AIFENCE composes Quality, Guard, and Bus into one FastAPI application with shared identity, database, audit correlation, telemetry, and lifecycle—without collapsing their domain responsibilities.

aifence.core

Shared configuration, database Base/engine, middleware, errors, metrics, telemetry, request identity, and environment helpers.

Quality

Native root router and deterministic admission evaluator plus explicit Deep Quality bridge.

Guard

Mounted enforcement sub-application, shared DB/identity, policy/capability/audit internals.

Bus

Mounted semantic transport with durable DB source-of-truth and optional broker fan-out.

One migration history

Every subsystem model shares the same declarative Base and Alembic history; migration/model drift is tested.

Composition seam

Register, don’t hard-wire.

aifence.app.create_app()
  ├─ core middleware / identity / metrics / OpenAPI
  ├─ quality.register(app, ctx)
  ├─ guard.register(app, ctx)
  └─ bus.register(app, ctx)

POST /v1/fence/submit
  → Quality admission
  → Guard enforcement
  → durable Bus handoff
  → fence.completed audit

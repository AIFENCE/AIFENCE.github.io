Security model

Shared identity, content classification, evidence, controlled egress, and an intentionally fail-closed posture.

#One identity model

Every authenticated AIFENCE surface uses the same API keys Guard issues. The fence flow, quality endpoints and operator console are explicitly bound to that provider rather than receiving a weaker credential path.

| Surface | Authentication | | --- | --- | | /health/live, /health/ready, /metrics | Public where configured for probes/scrapers. | | /v1/fence/submit | API key with decisions:write. | | /v1/quality/* | API key. | | /v1/console/* | API key with decisions:read. | | /guard/* | Guard router-level authentication. |

#Scopes

Keys carry explicit scopes such as decisions:read, decisions:write, approvals:write, capabilities:issue, audit:anchor, policies:activate, memory:quarantine, and tenants:lifecycle.

#Content classification

Data classes can be declared by the caller, but enforcement does not trust declaration alone. AIFENCE inspects payloads and reports observed sensitive classes into the same exfiltration and secret-exposure rules.

| Class | Signal | Precision measure | | --- | --- | --- | | financial | Card numbers, IBANs | Card numbers must pass a Luhn check. | | government_id | National IDs | Structurally invalid ranges excluded. | | credential | AWS/GitHub/Slack keys, JWTs | Generic secrets require assignment context. | | secret | Private key blocks | Explicit PEM header. | | health | Clinical terminology | Reported signal. | | personal_data | Email, phone | Informational class. |

Matched sensitive values are never returned — the classifier reports class names and counts only.

#Fail-closed posture

  • A tier that cannot answer produces 503 unless an allowed advisory tier is configured to fail open.
  • Guard can never be configured to fail open.
  • Unknown policy constraints fail closed rather than being ignored.
  • A standby region refuses durable worker roles at startup.
  • An unknown bus backend fails at startup instead of silently disabling fan-out.
  • Production validation refuses to start until hardening requirements are met.

#Evidence

Decisions produce signed receipts. Events are written to a hash-chained audit log with periodic checkpoints that can be anchored to independently administered destinations.

#Network controls

Outbound calls are confined: HTTPS-only destinations, canonical path confinement, DNS revalidation with connection-time IP pinning, preserved TLS SNI and Host, no redirect following, controlled egress, and bounded response sizes.

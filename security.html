Assurance

Security model

A fail-closed posture built around shared identity, content classification, evidence, and explicit outcomes.

One identity model

The fence flow, quality endpoints, operator console, and guard surfaces authenticate against guard-issued credentials. There is no separate weaker path for composed endpoints.

Fail-closed by construction

Guard cannot be configured fail-open.

If the enforcement plane cannot render a verdict, the request does not proceed as if it were authorized.

Do not trust self-declaration

Callers may declare the data classes present in a payload, but classification inspects payload content as well. Under-declaring a payload therefore does not automatically bypass exfiltration controls.

Auditing and evidence

  • Policy decisions and stage outcomes are captured as evidence.
  • Audit checkpoints and anchors support verification workflows.
  • Transport failures stay distinguishable from successful handoff.
  • Security issues should be reported privately through the repository security process.

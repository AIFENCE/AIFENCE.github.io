Getting started

Install AIFENCE, mint a key, and run an artifact through the complete Quality → Guard → Bus fence.

#Install

AIFENCE targets Python 3.12+. Create an isolated environment and install the repository.

bash
python -m venv .venv
. .venv/bin/activate              # Windows: .venv\Scripts\activate
python -m pip install -e ".[dev]"

#Prove the complete fence locally

The fastest supported proof is the real composed demo. It creates an isolated database, a tenant/API key, runs Quality → Guard → Bus, claims the durable handoff as the receiver, and exits non-zero if the lifecycle is incomplete.

bash
aifence demo

#Diagnose your runtime

Validate resolved configuration, application/database construction, the packaged Quality registry and Bus protocol resources before running a persistent service.

bash
aifence doctor

#Run the service

Start the composed API, then bootstrap the first administrative identity in another terminal.

bash
aifence serve

# second terminal
aifence bootstrap --tenant-name acme

The API key is shown once. Store it immediately, then use it for governed endpoints.

#Submit through the complete fence

bash
export AIFENCE_API_KEY='replace-with-bootstrap-token'
curl -sS -X POST http://127.0.0.1:8080/v1/fence/submit \
  -H "Authorization: Bearer $AIFENCE_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{
    "artifact":"# Deployment note\n\nThe release artifact passed the required validation and rollback ownership is documented.",
    "content_type":"text/markdown",
    "receiver":"release-agent",
    "action":{"operation":"read"},
    "risk_score":10
  }'

A successful receipt identifies the Quality mode/profile, Guard matched rule/reason codes, tenant-scoped Bus workspace/message, request ID and signed audit event.

#Production note

Development defaults favor local startup. Production validation rejects SQLite, schema auto-create, interactive docs, wildcard hosts/CORS, unsafe in-memory transport, non-HTTPS public origins and weak private-metrics configuration. Run aifence doctor in the intended production environment before deployment.

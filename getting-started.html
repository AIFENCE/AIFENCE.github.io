Getting started

Install AIFENCE, bootstrap identity, and run an artifact through the full fence.

Install

AIFENCE targets Python 3.12+. Create an isolated environment and install the repository in editable mode.

bash
python -m venv .venv
. .venv/bin/activate          # Windows: .venv\Scripts\Activate.ps1
pip install -e ".[dev]"
Optional extras

postgres, s3, mcp, otel, quality, redis, kafka, rabbitmq, and bench.

Run the composed application

bash
aifence-api
curl http://127.0.0.1:8080/health/ready
json
{ "ready": true,
  "subsystems": ["aifence.quality", "aifence.guard", "aifence.bus"],
  "region_role": "active",
  "accepts_writes": true }

Submit through the fence

bash
curl -X POST http://127.0.0.1:8080/v1/fence/submit \
  -H "Authorization: Bearer $AIFENCE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "artifact": "# Q3 Report\n\nRevenue grew 12% to $4.2M.",
    "content_type": "text/markdown",
    "receiver": "analytics-agent",
    "action": { "operation": "read" }
  }'

What happens next

  • A placeholder-laden artifact stops at blocked_by_quality.
  • A destructive high-risk action can pass quality and stop at blocked_by_guard.
  • A full pass returns final_outcome: "handed_off" with a durable message ID.

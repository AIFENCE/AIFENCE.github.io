Version model

Independent platform, subsystem, SDK, and protocol versions without implying identical compatibility semantics.

#Source of truth

The executable version inventory lives in src/aifence/versions.py. Protocol compatibility is proven by TCK vectors rather than inferred from implementation package numbers.

bash
aifence version

#Release rule

A platform release may contain different component versions. A release is valid only when CI proves required SDKs/adapters conform to the protocol and package metadata matches the central inventory.

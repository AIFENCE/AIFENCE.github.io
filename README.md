# AIFENCE.github.io

Product site and technical documentation for **AIFENCE**, the governance and execution boundary for AI agents.

The homepage is a scroll-linked 3D product tour through the actual AIFENCE contract:

**agent intent → Quality → Guard → Bus → audit evidence**

It includes an interactive fence simulator, fail-closed scenario paths, tenant/replay demonstrations, inspectable 3D hotspots, guided mode, adaptive WebGL, reduced-motion and no-WebGL fallbacks, a command palette, compatibility/assurance topology, and product/enterprise information pages.

The existing deep technical documentation remains available for API, configuration, protocol, failure semantics, deployment, operations, SDKs and threat-model reference.

See [`README-IMMERSIVE-50.md`](README-IMMERSIVE-50.md) for the 50-item implementation matrix and deployment notes.

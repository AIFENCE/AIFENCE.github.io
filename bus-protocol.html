Bus protocol

Cross-language semantic handoff compatibility is governed by aifence/0.2, wire version 2, and a shared conformance kit.

#Protocol identity

The Bus implementation version and wire protocol are separate contracts. Current protocol identity is aifence/0.2 with wire version 2.

#Compatibility rules

  • Every packet is validated as wire v2 before expansion.
  • Canonical JSON, canonical MessagePack and SHA-256 digests must match shared vectors.
  • Invalid vectors must be rejected.
  • Python, JavaScript and Go consume the same central TCK vectors.
  • Adapter-local standalone copies must remain byte-identical to the central vectors.

#Change rule

Protocol changes require a new protocol/wire version or an explicitly backward-compatible TCK change. Bumping the Bus implementation package alone does not redefine wire compatibility.

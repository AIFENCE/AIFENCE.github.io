Configuration

The shared AIFENCE_ environment surface, resilience budgets, multi-region settings, policy profiles, and subsystem ownership.

Configuration is read from the environment (and optionally .env). Every current variable uses the AIFENCE_ prefix. Invalid production configuration is rejected at startup and validation reports every unmet requirement at once.

#Core

| Variable | Default | Purpose | | --- | --- | --- | | AIFENCE_ENVIRONMENT | development | development / test / staging / production. | | AIFENCE_RUNTIME_ROLE | control-plane | Runtime role. | | AIFENCE_LOG_LEVEL | INFO | Root log level. | | AIFENCE_BIND_HOST | 0.0.0.0 | Bind host. | | AIFENCE_BIND_PORT | 8080 | Bind port. | | AIFENCE_PUBLIC_BASE_URL | http://localhost:8080 | Advertised OpenAPI base URL. | | AIFENCE_DOCS_ENABLED | true | Expose docs/OpenAPI. | | AIFENCE_MAX_REQUEST_BYTES | 2097152 | Global request body ceiling. |

#Persistence

| Variable | Default | Purpose | | --- | --- | --- | | AIFENCE_DATABASE_URL | sqlite+pysqlite:///./aifence.db | SQLAlchemy URL. | | AIFENCE_DB_POOL_SIZE | 20 | Pool size (non-SQLite). | | AIFENCE_DB_MAX_OVERFLOW | 20 | Pool overflow. | | AIFENCE_AUTO_CREATE_SCHEMA | true | Dev schema creation; use Alembic in production. |

#Fence flow resilience

| Variable | Default | Purpose | | --- | --- | --- | | AIFENCE_FLOW_QUALITY_TIMEOUT_SECONDS | 5.0 | Quality latency budget. | | AIFENCE_FLOW_GUARD_TIMEOUT_SECONDS | 5.0 | Guard latency budget. | | AIFENCE_FLOW_BUS_TIMEOUT_SECONDS | 10.0 | Bus latency budget. | | AIFENCE_FLOW_FAILURE_THRESHOLD | 5 | Failures before breaker trip. | | AIFENCE_FLOW_RECOVERY_SECONDS | 30.0 | Recovery probe window. | | AIFENCE_FLOW_FAIL_OPEN_TIERS | empty | Advisory tiers permitted to fail open. Only Quality and Bus. |

Guard cannot be made fail-open. Naming it is rejected at startup.

#Multi-region and transport

| Variable | Default | Purpose | | --- | --- | --- | | AIFENCE_REGION | empty | Region identifier. | | AIFENCE_REGION_ROLE | active | active owns writes/workers; standby serves reads. | | AIFENCE_BUS_TRANSPORT | none | none, memory, redis, kafka, rabbitmq. | | AIFENCE_BUS_TRANSPORT_URL | empty | Broker URL. | | AIFENCE_BUS_TRANSPORT_TOPIC | aifence.handoffs | Stream/topic/exchange name. |

#Policy profiles

AIFENCE_GUARD_POLICY_FILE selects the policy document. Two measured profiles ship: strict and balanced. Balanced is designed to reduce approval friction while preserving the evaluated detection behavior when behavioral analysis is enabled.

#Secrets

For secret-backed variables, <NAME>_FILE can point to a mounted secret file. This lets containers and Helm consume secrets without placing them in pod specs.

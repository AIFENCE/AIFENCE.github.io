Configuration

The shared AIFENCE_ environment surface, resilience budgets, multi-region settings, policy profiles, and subsystem ownership.

Configuration is read from the environment (and optionally .env). Every current variable uses the AIFENCE_ prefix. Invalid production configuration is rejected at startup and validation reports every unmet requirement at once.

#Core

VariableDefaultPurpose
AIFENCE_ENVIRONMENTdevelopmentdevelopment / test / staging / production.
AIFENCE_RUNTIME_ROLEcontrol-planeRuntime role.
AIFENCE_LOG_LEVELINFORoot log level.
AIFENCE_BIND_HOST0.0.0.0Bind host.
AIFENCE_BIND_PORT8080Bind port.
AIFENCE_PUBLIC_BASE_URLhttp://localhost:8080Advertised OpenAPI base URL.
AIFENCE_DOCS_ENABLEDtrueExpose docs/OpenAPI.
AIFENCE_MAX_REQUEST_BYTES2097152Global request body ceiling.

#Persistence

VariableDefaultPurpose

#Fence flow resilience

VariableDefaultPurpose
AIFENCE_FLOW_QUALITY_TIMEOUT_SECONDS5.0Quality latency budget.
AIFENCE_FLOW_GUARD_TIMEOUT_SECONDS5.0Guard latency budget.
AIFENCE_FLOW_BUS_TIMEOUT_SECONDS10.0Bus latency budget.
AIFENCE_FLOW_FAILURE_THRESHOLD5Failures before breaker trip.
AIFENCE_FLOW_RECOVERY_SECONDS30.0Recovery probe window.
AIFENCE_FLOW_FAIL_OPEN_TIERSemptyAdvisory tiers permitted to fail open. Only Quality and Bus.

Guard cannot be made fail-open. Naming it is rejected at startup.

#Multi-region and transport

VariableDefaultPurpose
AIFENCE_REGIONemptyRegion identifier.
AIFENCE_REGION_ROLEactiveactive owns writes/workers; standby serves reads.
AIFENCE_BUS_TRANSPORTnonenone, memory, redis, kafka, rabbitmq.
AIFENCE_BUS_TRANSPORT_URLemptyBroker URL.
AIFENCE_BUS_TRANSPORT_TOPICaifence.handoffsStream/topic/exchange name.

#Policy profiles

AIFENCE_GUARD_POLICY_FILE selects the policy document. Two measured profiles ship: strict and balanced. Balanced is designed to reduce approval friction while preserving the evaluated detection behavior when behavioral analysis is enabled.

#Secrets

For secret-backed variables, <NAME>_FILE can point to a mounted secret file. This lets containers and Helm consume secrets without placing them in pod specs.

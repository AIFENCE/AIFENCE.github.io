Reference

Configuration

AIFENCE uses a shared environment configuration surface with the AIFENCE_ prefix.

Configuration model

Configuration is owned by the shared core and passed into subsystem registration, keeping every tier on the same runtime settings and database foundation.

Environment

Prefer AIFENCE_* environment variables. A small legacy set may remain supported for backwards compatibility, but new deployments should use the shared prefix.

Recommended categories

Core

Database, region role, service identity, logging.

Security

API keys, policy posture, detector and evidence settings.

Resilience

Latency budgets, circuit breakers, retries and degradation policy.

Transport

Bus backend, fan-out integrations, storage and claim settings.

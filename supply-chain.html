Supply chain

Release integrity certifies built artifacts, protocol fixtures, generated Quality outputs, dependencies, and clean-install behavior.

#Required release path

  1. Lint, strict type-check and Python tests with enforced coverage.
  2. Red-team, security, architecture, invariant and release-consistency gates.
  3. Build/test canonical Quality runtime from source.
  4. Build/test Python, TypeScript and Go SDKs and required adapters.
  5. Run Bus TCK across required implementations.
  6. Build Python wheel and source archive.
  7. Verify package integrity and smoke/conformance-test the clean wheel.
  8. Generate vulnerability and SBOM artifacts.
  9. Publish checksums/provenance; sign artifacts/images where supported.

#Generated Quality tree

quality/build/ is generated output, not source-of-truth. quality/source/ plus deterministic tooling reconstructs it. The small control-registry snapshot shipped in the wheel is checked byte-for-byte against canonical source.

#Dependency policy

Dependency changes should pass the complete release gate, not merely an individual package build. Production dependencies remain explicitly bounded or pinned where reproducibility/signature review requires it.

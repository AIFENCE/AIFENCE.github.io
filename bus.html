Bus tier

The semantic communication runtime — durable handoffs, content-addressed references, learned patterns, and minimum-sufficient state.

The Bus tier is a vendor-neutral semantic communication runtime. It carries the minimum state a downstream agent needs rather than resending whole conversations: content-addressed references, immutable deltas, learned compositional patterns, provenance, and a model of what the receiver already knows.

#Durable delivery

text
handoff ──▶ pending ──▶ claimed ──▶ acknowledged
                          │
                          └─▶ lease expiry ──▶ claimable again

A handoff is committed to the database before it is considered delivered. Receiver knowledge advances only after acknowledgement, so a claimed but unacked message is redelivered rather than lost.

#Semantic compression

The bus compresses meaning rather than bytes. Negation, amounts, identities, authorization, deadlines, environment markers, instructions and constraints take the strict preservation path. Unknown or ambiguous meaning remains literal or referenced.

#Learned patterns

Recurring semantic structures move through candidate, shadow validation and counterfactual evaluation before becoming active. Promotion accounts for frequency, savings, stability, ambiguity, source trust/diversity, holdout evidence and receiver-specific fidelity.

#Content-addressed references

Stored content uses SHA-256 identity. Authorization and lifetime are separate grants, so identical bytes deduplicate without sharing authorization. Grants support workspace/owner scope, agent ACLs, field paths, memory tier, TTL, provenance and optional AES-GCM encryption at rest.

#Broker transports

| Backend | Mechanism | Extra | | --- | --- | --- | | none | No fan-out (default) | — | | memory | In-process, for tests | — | | redis | Redis Stream (XADD) | redis | | kafka | Topic keyed by receiver | kafka | | rabbitmq | Durable topic exchange | rabbitmq |

Publication follows the durable commit, and events carry identity/routing metadata rather than semantic content. A broker outage is reported in the receipt instead of being converted into a false success.

#Protocol and conformance

The bus reads and writes sage/0.2, wire version 2. Protocol identity is canonical MessagePack plus SHA-256; JSON is the readable representation. A language-neutral conformance kit of 13 normative vectors (6 valid, 7 invalid) is consumed independently by Python, JavaScript and Go implementations.

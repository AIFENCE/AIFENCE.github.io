Deployment

Migrations, containers, Helm, production hardening, multi-region active/standby topology, and broker transports.

#Database migrations

Production should run with AIFENCE_AUTO_CREATE_SCHEMA=false; Alembic is the only thing that creates tables.

bash
alembic upgrade head

A test asserts migrations produce the declared models and the history has one head, preventing silent schema drift.

#Container

bash
docker compose up --build      # PostgreSQL + the control plane

The image runs as a non-root user and serves aifence-api on port 8080.

#Helm

The chart lives under deploy/helm/aifence and deploys the control plane plus dispatcher, lifecycle and audit-anchor worker roles, migration job, network policy, HPA, PDB and ingress.

bash
helm upgrade --install aifence deploy/helm/aifence -f my-values.yaml

#Production validation

Production refuses to start without the configured hardening requirements, including verified TLS for PostgreSQL, mTLS, external KMS/non-exportable signing, durable evidence storage, independent audit anchoring, controlled egress and workload identity.

#Multi-region topology

Exactly one region is active: it owns the writable database and durable workers. Other regions are standby: they can serve the control plane from replicas and remain warm for promotion.

yaml
# active
region: { name: eu-west-1, role: active }
# standby
region: { name: us-east-1, role: standby }

Three independent guardrails prevent a standby from behaving like the active region:

  1. Startup validation refuses standby + durable worker role.
  2. The Helm chart does not render durable workers/migration outside the active region.
  3. Readiness publishes accepts_writes, so a global load balancer sends writes only to active.

#Bus transports

bash
AIFENCE_BUS_TRANSPORT=redis
AIFENCE_BUS_TRANSPORT_URL=redis://redis:6379/0
AIFENCE_BUS_TRANSPORT_TOPIC=aifence.handoffs

Publication happens after the durable commit and carries routing identity rather than semantic content.

#Health and observability

| Path | Purpose | | --- | --- | | /health/live | Liveness probe. | | /health/ready | Readiness; reports region and accepts_writes. | | /metrics | Prometheus scrape target. |

Set AIFENCE_OTEL_EXPORTER_OTLP_ENDPOINT to enable OpenTelemetry tracing.

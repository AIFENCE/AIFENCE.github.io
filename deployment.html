Operations

Deployment

Ship the composed control plane with migrations, health checks, production configuration, and active/standby guardrails.

Production posture

  • Apply the merged migration history before serving production traffic.
  • Use dedicated secrets for API identity and backend credentials.
  • Configure durable PostgreSQL for shared state; SQLite is suitable for local development.
  • Use the provided Helm chart for control-plane and worker roles.
  • Use health and readiness endpoints for load balancers and orchestration.

Health checks

bash
curl http://127.0.0.1:8080/health/live
curl http://127.0.0.1:8080/health/ready

Multi-region

AIFENCE supports an active/standby topology. Startup, chart, and load-balancer guardrails prevent a standby from accepting writes as if it were active.

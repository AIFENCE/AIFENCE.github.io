Reference

API reference

The composed application exposes a unified fence plus dedicated Quality, Guard, Bus, and operator surfaces.

OpenAPI is authoritative

When docs are enabled, the application OpenAPI document is the contract. The repository documentation can be regenerated from it to avoid drift.

Fence flow

POST/v1/fence/submit

Run one artifact through quality → guard → bus.

Quality

GET/v1/quality/controls

List quality controls.

POST/v1/quality/evaluate

Evaluate an artifact.

GET/v1/quality/registry

Read the registry summary.

Guard surface

The enforcement plane exposes resources for agents, API keys, approvals, artifacts, audit anchors, budgets, capabilities, decisions, delegations, executions, incidents, memory, policies, protocols, providers, tools, traces, tenant lifecycle, and workload identities under /guard/v1/*.

Bus surface

The semantic transport subsystem is mounted beneath /bus and manages durable state exchange and claimable handoffs.

Operator console

GET/v1/console/status

Operational status across all fence tiers.

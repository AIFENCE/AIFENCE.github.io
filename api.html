API reference

The composed OpenAPI 3.1 surface: fence flow, Quality, Guard, Bus and operator endpoints.

The authoritative contract is the composed application's /openapi.json when documentation is enabled. This site highlights stable high-value surfaces and avoids hardcoding an endpoint count that can drift between release candidates.

#Fence flow

MethodPathPurpose
POST/v1/fence/submitQuality → Guard → durable Bus → completion audit

#Quality

MethodPathPurpose
GET/v1/quality/controlsList admission/control metadata
POST/v1/quality/evaluateRun admission evaluator
GET/v1/quality/registryRegistry summary
POST/v1/quality/deep/planPlan Deep Quality 2.0 evaluation/evidence

#Guard

Guard is mounted under /guard/v1/* with resources for decisions, capabilities, approvals, policies, tools/executions, artifacts, audit, protocols, tenant lifecycle, workload identity and more.

#Bus

Bus is mounted under /bus/v1/* with durable handoff, claim/ack, references, routing, protocol/TCK, evaluation and integration surfaces.

#API discovery

Generate clients and schemas from the live composed /openapi.json; use the Bus TCK rather than OpenAPI alone for cross-language wire compatibility.

Operations

Run the fence with operator status, health probes, Prometheus metrics, OpenTelemetry traces, and explicit degradation signals.

#Operator console

GET /v1/console/ renders operator state; GET /v1/console/status returns JSON. The view ties durable handoffs, approvals, subsystem state, Quality registry and transport configuration together.

#Health probes

PathUse
/health/liveProcess liveness
/health/readyReadiness, region and accepts_writes

#Canonical fence telemetry

One request ID spans Quality, Guard, Bus, logs/traces and the completion audit.

MetricPurpose
aifence_fence_stage_calls_total{tier,result,breaker_state}Per-tier outcome/circuit state
aifence_fence_stage_duration_seconds{tier}Per-tier latency
aifence_fence_outcomes_total{outcome,allowed}Final fence outcomes

#Metrics access

/metrics is private by default. Production private metrics require a bearer token of at least 32 bytes unless public metrics are deliberately enabled.

#Tracing

AIFENCE_OTEL_EXPORTER_OTLP_ENDPOINT enables OpenTelemetry export. Content payloads are not placed into span attributes; exporter failure must not mutate policy outcomes.

#Audit linkage

Every completed fence flow appends fence.completed. The receipt exposes audit event ID, sequence, event hash and signing key ID so an operator can reconstruct request → admission → Guard → Bus → audit.
